# استوديو الرسوم في MIZYAi — الأنواع والمتطلبات والحدود

كل الرسوم تُحسب محلياً في المتصفح عبر DuckDB-WASM (المحرك مستضاف في `public/duckdb`، والـ CDN احتياطي فقط).
المسار: `ChartConfig → buildSql → صفوف → normalizeChartRows → ChartPoint[] → buildEChartsOption → EChartsView`.

## الأنواع ومتطلباتها
| النوع | المتطلب |
|---|---|
| bar / horizontalBar / line / area / pie | فئة في X ومقياس في Y (أو COUNT) |
| stacked / heatmap | فئة + «تقسيم السلاسل» (حتى 8 سلاسل، والباقي «أخرى») |
| combo | «مقياس ثانٍ» يُرسم خطاً على محور ثانوي |
| funnel / treemap | قيم غير سالبة |
| waterfall | قيم تغيّر (موجبة وسالبة) |
| radar | 3–12 فئة بقيم غير سالبة |
| histogram | عمود رقمي في Y؛ 20 مجالاً |
| boxplot | فئة + عمود رقمي (لا تجميع) |
| scatter | عمودان رقميان؛ عيّنة حتمية حتى 500 صف |

عند عدم توفر المتطلبات يُعرض سبب واضح، أو يُعاد التصوير تلقائياً كأعمدة مع تنبيه (`resolveChartFit`).

## الحدود
- أقصى صفوف نتيجة مرسومة: `CHART_ROW_CAP`؛ فوق 14 فئة يظهر تكبير وتنقل (`+ − ← → 0`).
- الجدول البديل يعرض أول 50 صفاً. قوالب التنسيق: 20 كحد أقصى، محفوظة في المتصفح فقط.
- ملف الإعدادات المستورد ≤ 100KB، ويُتحقق منه بقائمة بيضاء (لا بيانات ولا SQL فيه).
- اقتراحات AI: اختيارية، موافقة سحابية منفصلة، حمولة ≤ 30 نقطة مجمّعة + المخطط، وتُعرض قبل الإرسال.

## الإتاحة
وصف دلالي لكل رسم، جدول بديل، احترام `prefers-reduced-motion` و`prefers-contrast` (أنماط تعبئة)، وتحكم كامل بالكيبورد للتكبير.

## التصدير
PNG (1×–4× وخلفية شفافة)، SVG، CSV للنقاط المرسومة (مع حماية من حقن الصيغ)، وملف إعدادات JSON.

## ترقية DuckDB
بعد ترقية `@duckdb/duckdb-wasm` شغّل `node scripts/sync-duckdb-assets.mjs`؛ اختبار `duckdb-assets` يفشل إن نُسي.

## التحقق قبل كل نشر
`npx tsc --noEmit -p .` ثم `npx vitest run` ثم `npx vite build`.
