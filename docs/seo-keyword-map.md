## Editorial rules

- Keep each guide focused on its own search intent; do not repeat the same primary phrase across all articles.
- Use the primary phrase naturally in the title/H1 and opening paragraph where it accurately describes the page.
- Add contextual links between related guides when they help the reader complete the next task.
- Keep product-led language on the home page; guides should primarily answer the user's task, not repeat the brand name.
- Do not add a `meta keywords` tag or invent search-volume estimates.
- Canonical URLs remain on the existing Lovable domain until a verified MIZYAi domain and migration plan are available.
